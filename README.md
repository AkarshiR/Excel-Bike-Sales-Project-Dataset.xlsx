# Excel-Bike-Sales-Project-Dataset.xlsx

# Tools: Microsoft Excel (Pivot Tables, Charts, Slicers, Data Cleaning)

# Description:

Built a dynamic dashboard to analyze and visualize bike sales data across various dimensions such as customer demographics, product categories, geography, and order status. Performed data cleaning and transformation using Excel functions, created interactive Pivot Tables and Charts, and added slicers for user-driven filtering. Key insights included identifying high-performing customer segments, seasonal sales trends, and product category performance.

# Key Highlights:

1. Cleaned and structured raw transactional data for reporting.

2. Used PivotTables to summarize data by gender, income, region, and category.

3. Visualized trends with bar charts, pie charts, and line graphs.

4. Created slicers for interactive filtering based on Year, Category, and Region.

5. Enabled data-driven decision-making with actionable insights.
